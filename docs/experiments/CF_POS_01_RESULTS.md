# CF-POS-01 Frozen Results

## Experiment

CF-POS-01

## Objective

Evaluate whether significant seismic event clusters show a statistically non-random temporal association with historical alert episodes.

## Inputs

- Frozen alert episodes
- Frozen event clusters
- Frozen configuration

## Validation

- Input hashes verified
- Configuration verified
- Frozen workflow executed
- Placebo experiment completed
- Prospective interpretation boundary respected

## Outputs

The workflow automatically produces:

- observed_metrics.json
- placebo_summary.json
- robustness_checks.csv
- evidence_report.md

## Evidence Classification

The final evidence classification is determined exclusively from the frozen workflow outputs.

Possible outcomes:

- Temporally specific
- Preliminary
- Non-discriminating
- Inconclusive (low power)

## Reproducibility

The experiment is fully deterministic.

All outputs are reproducible from:

- identical frozen inputs
- identical configuration
- identical software revision
