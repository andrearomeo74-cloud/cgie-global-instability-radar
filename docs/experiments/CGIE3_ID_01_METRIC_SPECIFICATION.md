# CGIE3-ID-01 Metric Specification

Version: 0.1 (Draft)

---

# 1. Purpose

This document specifies the first experimental implementation of
the Congruity identity metrics for CGIE-3.

The objective is not earthquake prediction.

The objective is to determine whether the structural identity of a
seismic system degrades before significant seismic events.

---

# 2. Scope

Domain:

Campi Flegrei

Experiment:

CGIE3-ID-01

Status:

Experimental

---

# 3. Scientific Question

Can changes in the relational organization of seismic features be
measured before the occurrence of significant earthquakes?

---

# 4. Input

The experiment uses the frozen feature table generated by
CF_RETRO_01.

No future information may be used.

---

# 5. Candidate Identity

The identity of the seismic system is represented by the
relationships among the selected features rather than by the
features individually.

Individual variables are considered observable projections.

The candidate identity is therefore relational.

---

# 6. Primary Relations

Only reproducible relations may belong to the candidate identity.

Each relation must satisfy predefined eligibility criteria before
being included.

---

# 7. Secondary Relations

Relations that are informative but not essential are classified as
secondary.

Secondary relations may support interpretation but must not define
identity.

---

# 8. Frozen Baseline

The identity network is constructed only from the baseline period.

The baseline remains frozen throughout the experiment.

No future observation may modify the baseline.

---

# 9. Identity Network

The candidate identity is represented as a graph.

Nodes correspond to selected features.

Edges correspond to validated relations.

---

# 10. Experimental Metrics

The first implementation evaluates only experimental technical
metrics.

Canonical Congruity metrics remain reserved until validation is
completed.

---

# 11. Interpretation Boundary

Changes in the identity network indicate structural transition.

They do not constitute deterministic earthquake prediction.

---

# 12. Validation

Every metric introduced in this experiment must be evaluated using:

- placebo periods;
- random controls;
- ablation studies;
- robustness analyses;
- reproducibility checks.

No metric is considered validated before passing these tests.
